Courses & repas simples

Objectif : faire des repas salés, faciles, peu coûteux et adaptés à neuf personnes. Les quantités sont à ajuster selon l’appétit.

Repas proposés

  • Dimanche : barbecue (merguez, poulet, légumes, pain).
  • Déjeuners : salades de pâtes / riz / taboulé, sandwichs, fruits.
  • Dîners : fajitas, pâtes bolognaise, wraps, pizzas maison ou plancha.
  • Samedi brunch : œufs, pain, fruits, viennoiseries.

Astuce : un gros repas viande le dimanche, puis des repas faciles à réchauffer les soirs de sortie.

Base de courses

  • Féculents : pâtes, riz, semoule, tortillas, pain.
  • Protéines : poulet, merguez, steak haché, thon, œufs.
  • Légumes : tomates, salade, poivrons, oignons, maïs.
  • Petit-déj : lait, café, céréales, pain, confiture, fruits.

Prendre marques distributeur et gros formats. Prévoir eau / glaçons / sacs poubelle séparément.

Organisation dimanche

  • Équipe 1 : repas & petit-déjeuners.
  • Équipe 2 : boissons, eau, snacks, glaçons.
  • Équipe 3 : hygiène, ménager, papier, charbon si barbecue.
  • Garder le ticket : ajout immédiat dans les comptes.

Faire un premier gros panier puis uniquement des petites courses d’appoint mardi et samedi.
